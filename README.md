# ESQUADRA Commerce

Sistema de loja e gestão de vendas para portas, janelas e esquadrias em FastAPI com interface HTML/CSS/JavaScript, SQLite e impressão de comprovantes personalizados.

Este repositório está recebendo os arquivos do projeto. A documentação de instalação completa acompanha o código-fonte.

> Antes de publicar o sistema na internet, configure a conta administrativa em ambiente seguro, HTTPS e armazenamento persistente.
